# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Book lovers, readers, and digital library managers who read EPUBs and PDFs on desktop and mobile devices.

## Product Purpose

Bookxboi is an elegant, immersive web book reader and digital bookshelf app designed for seamless reading experiences with rich typography, reader customization, and intuitive navigation.

## Positioning

A minimalist, high-craft web reading app focused on typographic excellence, glassmorphic UI, and distraction-free book reading.

## Operating Context

Web browser environment on desktop and mobile devices.

## Capabilities and Constraints

- EPUB and PDF reading capabilities via epubjs and pdfjs-dist
- Customizable reader settings (font size, theme, line height, layout)
- Modern Next.js application built with React 19 and Tailwind CSS

## Brand Commitments

- Name: Bookxboi
- Visual style: Warm canvas themes, Playfair & Inter typography, refined glassmorphism, editorial elegance.

## Product Principles

1. Typography first: prioritize reading comfort and legibility.
2. Distraction-free: UI recedes so content shines.
3. Fluid & tactile: smooth transitions and glassmorphic micro-interactions.
